# WeatherX

A clean, responsive React weather dashboard powered by Open-Meteo.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Features

- Search any city
- Current weather and feels-like temperature
- Today's high and low
- 5-day forecast
- Next-hours forecast
- Humidity, wind, pressure, visibility and UV index
- Loading and city-not-found states
- Responsive desktop and mobile layout
- No API key or `.env` file required
